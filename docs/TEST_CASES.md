# 测试用例（验收清单）

> 本清单需要在真机（iPhone 13 / iOS 16.0.2）或同一局域网的电脑上执行。  
> 由于当前开发环境是 Windows、无法运行 Xcode，仓库通过 GitHub Actions 构建；测试结果请以实际设备/CI 日志为准。

## 0. 测试准备

- 一台 iPhone（已安装 PitHub），与电脑同一 Wi-Fi。
- 电脑浏览器、curl、可选 WebDAV 客户端（Finder / Windows / Solid Explorer）。
- 默认密码 `pithub`，测试前记录端口（默认 8080）。
- 定义变量：

```bash
BASE=http://<iPhone IP>:8080
COOKIE=/tmp/pithub.cookies
```

---

分片续传最小验证：

```bash
# 初始化
curl -s -b $COOKIE -X POST $BASE/api/file/upload/init \
  -H 'Content-Type: application/json' \
  -d '{"path":"/uploads/ct.bin","size":10485760}' | tee /tmp/init.json
# 上传 index 0，然后查询 status，确认 received [0]
# 再补其余分片，complete
```
